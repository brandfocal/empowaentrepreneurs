Purpose: This document maps out the specific fields, data types, and configurations required to build Form ID 11 (Dragon Scoring Panel) inside Gravity Forms.

By matching these precise input IDs, submissions from the custom React frontend scorecard will map correctly to your WordPress entry database.

⚠️ Note: Due to field modifications in Gravity Forms, Session Track is mapped to ID 3 (input_3). Consequently, input_2 is bypassed, and all subsequent field IDs are shifted up by 1 place.

📋 Quick Setup Guide for Gravity Forms Dashboard

  1. Create or edit your form inside Gravity Forms titled Dragon Scoring Panel. Make sure it corresponds to ID 11.
  2. Arrange fields precisely matching the Field IDs table above. Note that `input_2` must remain unused or blank so that **Session Track** maps to **ID 3**.
  3. For numeric score fields, set Minimum Value = 1 and Maximum Value = 10.
  4. Save and publish the form. React submissions will now bind seamlessly to your WordPress dashboard databases!
