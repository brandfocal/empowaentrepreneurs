Summit Registration and Pitching Festival Core Workflows

Executive Summary

This specification outlines the business workflows for the core Summit Registration and the Pitching Festival. It describes how user submissions are processed, how confirmations are handled, and how records are aggregated for team administration.

Target Audience: Project Managers, Event Coordinators, Operations Directors.

Prepared For EmpowaEntrepreneurs Operations Team

Project Stage Technical Integration Done
Author Admissions & Tech Directors Group
1. Registration User Journey Page 02

EmpowaEntrepreneurs 2026 manages the primary event access registration channel for General Admission, corporate guests, and investors.

General Summit Registration Core Pipeline

  • Step 1: Attendee Sign-Up

    General attendees, investors, and corporate guests visit the 'Summit RSVP' modal on the website and fill out basic details (Name, Email, Cellphone, Company, Designation).

  • Step 2: Instant Database Entry

    Submission securely logs attendee records directly inside the WordPress backend dashboard tables.

  • Step 3: Double Email Dispatch

    The system dispatches two emails: a styled ticket confirmation to the Attendee, and a notification containing full registration details to the Admins.

  • Step 4: Spreadsheet Accumulation

    The record is automatically loaded into the Summit Attendance Spreadsheet in the WordPress backend, allowing event managers to export the full attendee list for printing credentials.

2. Pitching Festival Journeys Page 03

Details the entry process for founders pitching in the arena and the live evaluation scoring process by dragons during sessions.

Pitching Festival Entry Application Core Arena Pipeline

  • Step 1: Pitch Arena Audits

    Scale-up founders apply for pitching slots by filling out a thorough 6-step business assessment. This covers company registration, founder details, value proposition, TAM/SAM market size, financial figures, and document uploads (B-BBEE certificates, company structures, pitch decks).

  • Step 2: File Attachment Safeguard

    Gravity Forms securely uploads all pitch files and documents to dedicated directories on the web server.

  • Step 3: Dual-Stream Email Triggers

    The founder receives a pitch application confirmation. Admins receive an instant screening notification containing links to the uploaded files.

  • Step 4: Evaluation Board Sync

    The details and file paths populate the Pitching Festival Admissions Spreadsheet in WordPress, ready for the Investment Committee to review and select pitching finalists.

3. Live Scoring & Backend Sheets Page 04

Dragon Scorecard Panel (Live Evaluation) Live Event Flow

  • Step 1: Dragon Live Review

    During live pitches, evaluators ("Dragons") use a secure, custom frontend panel to select the startup and rate them on 8 weighted criteria (TAM, Business Model, Traction, Team, Financials, Moats, Deal Terms, ESG).

  • Step 2: Automated Score Calculation

    The custom page automatically calculates a weighted Total Score out of 100 on submission, saving the evaluator from manual math errors.

  • Step 3: Scorecard Database Storage

    The score and written feedback are sent via API to Form ID 11 inside Gravity Forms, where they are logged as a secure entry.

  • Step 4: Real-time Leaderboard Compilation

    The score and comments are appended to the Dragon Leaderboard Spreadsheet in WordPress, allowing directors to rank startups in real-time and select the winners of the funding commitments.

📊 The WordPress Backend Spreadsheet System

All user journey entries are saved directly inside WordPress in database-backed tables. Project managers do not need direct database access or developer support to view entries. You can view, filter, edit, or export submissions (e.g. as Excel spreadsheets) directly through the WordPress Admin Portal under Gravity Forms → Entries, or view them dynamically synced to Google Sheets or Excel plugins in the dashboard backend.
